# FormStore

Form store interface that provides reactive access to the state of a form created with <Link href="../injectForm/">`injectForm`</Link>.

  - `errors` <Property {...properties.errors} />

### Explanation

Every property of the form store is an Angular signal, so you call it as a function — both in your component class and in your template. Since the store is built from signals, it works with `OnPush` change detection and in zoneless applications without any subscriptions.

The `errors` property only contains validation errors at the root level of the form. These are errors from the root object schema validation itself, not errors from nested fields. To retrieve all validation errors from all fields across the entire form, use the <Link href="/methods/api/getDeepErrors/">`getDeepErrors`</Link> method instead.
