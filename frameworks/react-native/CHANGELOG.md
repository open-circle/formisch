# Changelog

All notable changes to the library will be documented in this file.

## v1.2.0 (October 31, 2026)

- Change `@formisch/core` to v1.1.0
- Change `@formisch/methods` to v1.1.0
- Fix fields no longer updating after their effects were re-created without a re-render, e.g. when `<Activity>` hides and reveals a form (issue #230)

## v1.1.1 (October 26, 2026)

- Change `@formisch/core` to v1.0.2
- Change `@formisch/methods` to v1.0.2

## v1.1.0 (September 07, 2026)

- Change `@formisch/core` to v1.0.1
- Change `@formisch/methods` to v1.0.1
- Add `@formisch/react-native/internals` to expose the framework-specific core for custom methods and building blocks

## v1.0.0 (August 20, 2026)
