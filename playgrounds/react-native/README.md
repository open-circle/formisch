# Formisch React Native Playground

An [Expo](https://expo.dev/) app demonstrating `@formisch/react-native` with the same five forms as the other playgrounds: login, payment, todos, special and nested. It is styled with [NativeWind](https://www.nativewind.dev/) (Tailwind CSS), supports light and dark mode, and runs on iOS, Android and the web via `react-native-web`.

## Development

From the repository root:

```bash
pnpm install
pnpm -C playgrounds/react-native dev     # run with the Expo dev server (press w for web, i/a for a simulator)
pnpm -C playgrounds/react-native web     # run in the browser via react-native-web
```
