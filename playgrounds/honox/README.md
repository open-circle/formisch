# Formisch HonoX Playground

This playground is a HonoX app with server-side rendering. Each form is an island that is rendered on the server and hydrated on the client, and imports Formisch from `@formisch/honox`.

```bash
pnpm dev      # Start the dev server
pnpm build    # Build the client and server
pnpm preview  # Start the built Node.js server
```
